# Orbit

Orbit คือเว็บติดตามดาวเทียมไทยแบบ 3D ที่พัฒนาโดย Spaceth ให้เห็นว่าดาวเทียมของไทยอยู่ตรงไหนเหนือโลก ผ่านเบราว์เซอร์ โดยไม่ต้องเปิดโปรแกรมติดตามเฉพาะทาง

เว็บเริ่มจากภาพถ่ายวงโคจรจริงที่เรียกว่า **OMM** แล้วคำนวณว่าดาวเทียมแต่ละดวงควรอยู่ที่ใด ณ เวลาบนนาฬิกา

## ทำไมถึงใช้ OMM แทน TLE

**TLE** (Two-Line Element) คือภาพถ่ายชุดเดียวกันที่เขียนเป็นตัวเลขสองบรรทัดตายตัว เหมือนแบบฟอร์มกระดาษเก่าที่แต่ละช่องมีความกว้างกำหนดไว้ หมายเลขในแคตตาล็อกสาธารณะ หรือ **NORAD ID** มีที่ว่างบนแบบฟอร์มนั้นเพียงห้าหลัก

CelesTrak แจ้งว่าหมายเลขห้าหลักหมดแล้ว ตั้งแต่วันที่ **2026-07-11** เมื่อเพิ่มดาวเทียม Saramago วัตถุที่ขึ้นทะเบียนใหม่ได้หมายเลข **หกหลัก** (100000 ขึ้นไป) และข้อมูลวงโคจรของวัตถุเหล่านั้นไม่ถูกเผยแพร่เป็น TLE อีกต่อไป ดูประกาศได้ที่ [A New Way to Obtain GP Data](https://celestrak.org/NORAD/documentation/gp-data-formats.php)

**OMM** (Orbit Mean-Elements Message) คือภาพถ่ายเดียวกันที่ทุกตัวเลขมีป้ายกำกับ มักอยู่ในรูป JSON หมายเลขแคตตาล็อกจึงยาวขึ้นได้ และเครื่องคิดเลขยังเป็นชุดเดิมคือ **SGP4** CelesTrak เรียกข้อมูลตระกูลนี้ว่า **GP** (general perturbations) OMM คือวิธีเขียนภาพถ่าย GP แบบมีป้ายกำกับ

## OMM คืออะไร

ให้นึกว่า OMM คือรูปถ่ายวงโคจรของดาวเทียม ถ่ายไว้ ณ วินาทีหนึ่ง รูปนั้นไม่ใช่รายการตำแหน่งในอนาคต แต่เป็นรูปร่างของเส้นทาง และตำแหน่งของดาวเทียมบนเส้นทางนั้นตอนถ่ายรูป

จากรูปนั้น เครื่องคิดเลขสามารถเดินวงโคจรไปข้างหน้าหรือย้อนหลังได้ ทั้งอีกไม่กี่นาที พรุ่งนี้ หรือเมื่อกี้นี้ Orbit ดาวน์โหลดรูปล่าสุดแล้วคำนวณในเบราว์เซอร์ ปุ่ม **Download OMM** บนดาวเทียมแต่ละดวงจะบันทึกระเบียนที่เว็บกำลังใช้อยู่

### ระเบียนหน้าตาเป็นอย่างไร

CelesTrak ส่ง JSON หนึ่งก้อนต่อหนึ่งดาวเทียม ด้านล่างคือระเบียนจริงของ THEOS-2 เมื่อวันที่ 7 กันยายน 2026 ตัดให้เหลือฟิลด์ที่ Orbit อ่าน ตัวเลขจริงเปลี่ยนตลอด ชื่อฟิลด์ไม่เปลี่ยน

```json
{
  "OBJECT_NAME": "THEOS-2 (T2V)",
  "OBJECT_ID": "2023-155A",
  "EPOCH": "2026-09-07T21:46:27.062688",
  "MEAN_MOTION": 14.81706045,
  "ECCENTRICITY": 0.00015312,
  "INCLINATION": 97.881,
  "RA_OF_ASC_NODE": 320.6123,
  "ARG_OF_PERICENTER": 90.3925,
  "MEAN_ANOMALY": 269.7463,
  "BSTAR": 0.000067931,
  "MEAN_MOTION_DOT": 0.00000483,
  "MEAN_MOTION_DDOT": 0,
  "NORAD_CAT_ID": 58016,
  "REV_AT_EPOCH": 15767,
  "CLASSIFICATION_TYPE": "U",
  "ELEMENT_SET_NO": 999,
  "EPHEMERIS_TYPE": 0
}
```

สำเนาที่ฝังไว้ใน `src/data/omm-fallback.json` คือระเบียนเดียวกัน ใช้ชื่อสั้นลง เช่น `meanMotion` และ `inclination`

### อ่านอย่างไร

**OBJECT_NAME** และ **NORAD_CAT_ID** คือชื่อกับหมายเลขแคตตาล็อก `58016` คือหมายเลขบัตรของ THEOS-2 ในแคตตาล็อกสาธารณะ **OBJECT_ID** `2023-155A` คือรหัสสากล: ปล่อยปี 2023 เป็นการปล่อยลำดับที่ 155 ของปีนั้น และเป็นชิ้น A ของเที่ยวนั้น

**EPOCH** คือเวลาบนรูปถ่าย ตัวเลขที่เหลืออธิบายวงโคจร ณ วินาทีนั้น SGP4 จึงพารูปนั้นไปยัง “ตอนนี้” หรือไปยังเวลาที่ไทม์ไลน์กำลังแสดง

**MEAN_MOTION** `14.817` คือจำนวนรอบที่ดาวเทียมโคจรรอบโลกในหนึ่งวัน เอา 24 ชั่วโมงหารด้วยตัวเลขนี้ ได้ประมาณ 97 นาทีต่อรอบ ดาวเทียมใกล้โลกหมุนรอบเร็ว ดาวเทียมที่ดูเหมือนค้างอยู่เหนือจุดเดิมบนโลกหมุนประมาณวันละรอบ

**ECCENTRICITY** `0.00015` บอกว่าวงรีถูกยืดมากแค่ไหน ศูนย์คือวงกลมสมบูรณ์ วงนี้เกือบกลม เหมือนเหรียญที่เบี้ยวเพียงเล็กน้อย จุดใกล้โลกที่สุดกับจุดไกลโลกที่สุดจึงสูงเกือบเท่ากัน

**INCLINATION** `97.881` องศา คือมุมเอียงของวงรีเทียบกับเส้นศูนย์สูตร ศูนย์องศาจะบินไปตามเส้นศูนย์สูตรและไม่เห็นขั้วโลก เก้าสิบองศาจะผ่านขั้วโลก มุมที่เลยเก้าสิบไปเล็กน้อยแบบนี้เป็นมุมที่ใช้กับดาวเทียมสำรวจโลก: แต่ละรอบพาดเกือบทุกละติจูด และมุมเอียงถูกเลือกให้แสงแดดบนพื้นดูคล้ายกันจากรอบหนึ่งไปอีกรอบ

**RA_OF_ASC_NODE** `320.6123` องศา บอกว่าวงรีที่เอียงอยู่นั้นถูกหมุนไปทางไหน นึกถึงห่วงที่ยืนเกือบตั้งตรงรอบโลก ตัวเลขนี้หมุนห่วงจนจุดที่ดาวเทียมตัดเส้นศูนย์สูตรขณะมุ่งเหนือ ตรงกับทิศนั้น

**ARG_OF_PERICENTER** `90.3925` องศา บอกว่าจุดที่ใกล้โลกที่สุดอยู่ตรงไหนบนวงรี **MEAN_ANOMALY** `269.7463` องศา บอกว่าตอนถ่ายรูป ดาวเทียมไปได้ไกลแค่ไหนบนรอบนั้น ศูนย์หมายถึง “อยู่ที่จุดใกล้โลกที่สุด” 180 หมายถึง “อยู่ที่จุดไกลที่สุด” 270 หมายถึงไปได้ประมาณสามในสี่ของรอบ ซึ่งคือตำแหน่งของ THEOS-2 ในภาพนี้

**BSTAR** เป็นตัวแทนของแรงต้านอากาศ แม้สูงหลายร้อยกิโลเมตรก็ยังมีอากาศบาง ๆ คอยฉุดดาวเทียมช้า ๆ **MEAN_MOTION_DOT** บอกว่าอัตรารอบเปลี่ยนไปเพราะแรงฉุดนั้นเท่าใด **MEAN_MOTION_DDOT** เป็นการแก้ที่ละเอียดกว่า และมักเป็นศูนย์

**REV_AT_EPOCH** `15767` คือจำนวนรอบบนรูปถ่าย THEOS-2 โคจรรอบโลกไปแล้วเท่านั้นรอบ

**CLASSIFICATION_TYPE** `U` หมายถึงไม่จัดชั้นความลับ **EPHEMERIS_TYPE** `0` หมายถึง “ใช้เครื่องคิดเลข SGP4 แบบปกติ” **ELEMENT_SET_NO** คือไฟล์นี้เป็นการอัปเดตครั้งที่เท่าใด

## จากรูปถ่ายไปเป็นตำแหน่งบนจอ

**SGP4** คือเครื่องฉาย ให้รูปถ่ายกับเวลา มันจะประมาณว่าดาวเทียมควรอยู่ที่ใด อากาศ ดวงอาทิตย์ และดวงจันทร์ยังดันดาวเทียมจริงอยู่ตลอด รูปที่ถ่ายวันนี้จึงคม รูปที่ถ่ายเมื่อหลายเดือนก่อนจะคลาดเคลื่อน นี่คือเหตุที่ Orbit ใช้ OMM ใหม่ และเก็บสำเนาไว้เมื่อเครือข่ายใช้ไม่ได้

**satellite.js** คือไลบรารี JavaScript ที่อ่าน JSON แล้วรัน SGP4

1. เว็บดาวน์โหลด OMM ของดาวเทียมแต่ละดวง
2. satellite.js เปลี่ยนระเบียนนั้นเป็นแบบจำลองวงโคจร
3. SGP4 ประมาณตำแหน่ง ณ เวลาบนนาฬิกา
4. Orbit แปลงตำแหน่งนั้นเป็นละติจูด ลองจิจูด ความสูง ความเร็ว และจุดในฉาก 3D
5. จุดนั้นถูกวาดบนโลก พร้อมเส้นของเส้นทาง

OMM คือรูปถ่าย SGP4 คือเครื่องฉาย satellite.js คือเครื่องยนต์ของเครื่องฉายในเบราว์เซอร์

## ข้อมูล OMM มาจากไหน

Orbit โหลดข้อมูล GP จาก **[CelesTrak](https://celestrak.org/)** (`gp.php` แบบ JSON ค้นด้วย NORAD ID)

เส้นทางบนเซิร์ฟเวอร์คือ `/api/omm/[id]` ระบบดึงเฉพาะหมายเลขที่อยู่ในรายการดาวเทียมของโปรเจกต์ จึงจำกัดอยู่ที่ยานเหล่านั้น ระเบียนใหม่ถูกเก็บไว้ประมาณหนึ่งชั่วโมง ภาพถ่ายวงโคจรหลังผ่านไปชั่วโมงหนึ่งยังใช้ได้ และการเก็บไว้ทำให้หน้าเว็บไม่ต้องถาม CelesTrak ทุกครั้งที่เปิด

ถ้าติดต่อ CelesTrak ไม่ได้ Orbit ใช้สำเนาใน `src/data/omm-fallback.json`

1. เซิร์ฟเวอร์ลอง CelesTrak ก่อน แล้วจึงส่งระเบียนที่ฝังไว้ของดาวเทียมนั้น
2. ถ้าเบราว์เซอร์เรียกเส้นทางบนเซิร์ฟเวอร์ไม่ได้ ก็ใช้ระเบียนชุดเดียวกัน โลกจึงยังขยับได้ตอนออฟไลน์

ข้อความผิดพลาดพร้อมปุ่ม **ลองอีกครั้ง** จะขึ้นเมื่อทั้งระเบียนสดและสำเนาที่ฝังไว้หายไป อัปเดตไฟล์ที่ฝังไว้จาก CelesTrak ประมาณสัปดาห์ละครั้งด้วยคำสั่ง

```bash
npm run update-omm-fallback
```

## โลก 3D

ลูกโลกวาดด้วย **Three.js** ผ่าน **React Three Fiber** Three.js คือเครื่องมือที่วางรูปทรง 3D ลงบนหน้าเว็บ React Three Fiber ให้รูปทรงเหล่านั้นอยู่ในอินเทอร์เฟซ React ชุดเดียวกับพาเนลและปุ่ม

แผ่นดินมาจาก Natural Earth เป็นรูปชายฝั่ง วางบนทรงกลมมหาสมุทร ไม่มีเส้นพรมแดนประเทศ เกาะเล็ก ๆ ถูกตัดออกเพื่อให้ลูกโลกโหลดเร็ว เมื่อเลือกดาวเทียม กล้องจะเข้าไปใกล้ เมื่อเลิกเลือก กล้องจะกลับมามองทั้งโลก

## มุมมองพื้นโลก

มุมมองอวกาศมองลงมาที่โลก มุมมองพื้นโลกเป็นกล้องอีกตัว อยู่ข้างปุ่มเปลี่ยนภาษา คุณยืนอยู่บนพื้นแล้วมองขึ้น

นึกถึงการยืนข้างนอกพร้อมกล้อง ทิศขึ้นคือเหนือศีรษะ ทิศเหนือคือเข็มทิศ และมือขวาชี้ไปทางตะวันออก ภาพเปิดโดยหันไปทางเหนือ เงยขึ้นจากขอบฟ้าเล็กน้อย การลากคือการคว้าท้องฟ้า ดาวจึงอยู่ใต้ตัวชี้ตลอด ล้อเมาส์ทำให้ภาพกว้างขึ้นหรือแคบลง ใต้ขอบฟ้า พื้นเป็นทรงกลมเรียบ รูปแผ่นดินยังอยู่เฉพาะในมุมมองอวกาศ

การเลือกสถานที่ในรายการ หรือ **ตำแหน่งของฉัน** ในมุมมองอวกาศ จะหมุนลูกโลกให้จุดนั้นอยู่กลางภาพ การลากลูกโลกจะปล่อยให้มองไปทางอื่นได้

ดาวเทียมที่เลือกใช้ตำแหน่ง SGP4 ชุดเดียวกับมุมมองอวกาศ กล้องหันไปหาดวงนั้นและรักษาให้อยู่กลางภาพตามนาฬิกา การลากท้องฟ้าจะปล่อย การเลือกดาวเทียมอีกครั้งจะจับใหม่ ตัวควบคุมเวลายังขยับท้องฟ้า ดวงจันทร์ ดาวเทียม และเส้นวงโคจรไปด้วยกัน เหมือนการเลื่อนวิดีโอเรื่องเดียวกัน

กล่องตำแหน่งเริ่มต้นแบบปิด สถานที่ถูกจัดกลุ่มไว้ใน `src/data/cities.json`

| กลุ่ม | สถานที่ |

### ท้องฟ้ามาจากไหน

ดาวบนท้องฟ้าคือดวงที่ตาคนมองเห็นในคืนฟ้ามืดแจ้ง ลงไปถึงโชติมาตร 6 โชติมาตรคือมาตราสว่างแบบเก่า เลขน้อยสว่างกว่า และ 6 คือประมาณดาวจางที่สุดที่ตาเปล่ายังแยกได้ บัญชีดาวคือ **XHIP** ซึ่งต่อจาก Hipparcos (Anderson & Francis, 2012) ตามที่เผยแพร่ใน [d3-celestial](https://github.com/ofrohn/d3-celestial) ของ Olaf Frohn เส้นกลุ่มดาวเป็นรูปของสหพันธ์ดาราศาสตร์สากล พร้อมการปรับเส้นของ Frohn จากโปรเจกต์เดียวกัน Orbit เก็บสำเนาย่อไว้ใน `src/data/skymap.json`

ดาวแต่ละดวงถูกเก็บเป็นไรต์แอสเซนชันและเดคลิเนชัน ซึ่งคือลองจิจูดกับละติจูดบนท้องฟ้า วาดไว้สำหรับปี 2000 ในแต่ละเฟรม satellite.js ให้เวลาดาวฤกษ์กรีนิช คือเวลาของดาว ซึ่งเดินเร็วกว่านาฬิกาแขวนเล็กน้อยเพราะโลกโคจรรอบดวงอาทิตย์ แล้วหมุนแผนที่นั้นเข้ากรอบยึดโลกชุดเดียวกับดาวเทียม ท้องฟ้ากับดาวเทียมจึงใช้นาฬิกาเดียวกัน

ดวงจันทร์ใช้ตำแหน่งแบบศูนย์กลางโลกที่ง่ายกว่าใน `src/lib/moon.ts` ซึ่งอยู่ในกรอบยึดโลกอยู่แล้ว จึงปรากฏทั้งสองมุมมอง

## Orbit ทำอะไรได้บ้าง

ดาวเทียมไทยหลายดวงอยู่บนลูกโลกพร้อมกันได้ เลือกดวงหนึ่งเพื่อดูตำแหน่ง ความสูง ความเร็ว ภารกิจ วันปล่อย และหน่วยงาน ซ่อนดวงที่ไม่ต้องการได้

ไทม์ไลน์เลื่อนได้ประมาณสามวันก่อนและหลังตอนนี้ และเล่นได้เร็วกว่าเวลาจริง พยากรณ์การผ่านแสดงสามวันข้างหน้าจากจุดที่เลือก ได้แก่ วันที่ เวลาที่ขึ้นเหนือขอบฟ้า มุมสูงสุด และระยะเวลาที่ดาวเทียมอยู่บนฟ้า เมื่อเลือกแต่ละครั้ง นาฬิกาจะกระโดดไปตอนดาวเทียมขึ้น การนับเป็น T− ก่อนดาวเทียมพ้นขอบฟ้า และเป็น T+ หลังจากนั้น พร้อมเข็มทิศตอนขึ้นและตอนตก ดาวเทียมที่ไม่ตกจะบอกว่าอยู่เหนือคุณตลอดเวลา รายการบันทึกเป็น CSV ได้

**ดาวเทียมของฉัน** เก็บไว้ในเบราว์เซอร์เครื่องนี้เท่านั้น ติดตามวัตถุในแคตตาล็อกจาก NORAD ID หรือ TLE ด้วยฟีด OMM เดียวกัน เปลี่ยนชื่อได้ และคลิก NORAD ID เพื่อคัดลอก

path เช่น `/theos-2` จะเปิดดาวเทียมนั้น จากนั้นที่อยู่จะอยู่ที่ `/` การเลือกดาวเทียมดวงอื่นจึงไม่โหลดลูกโลกใหม่

## Tech stack

**Next.js** คือโครงของเว็บ ทั้งหน้าเพจและเส้นทางบนเซิร์ฟเวอร์ที่ดึง OMM **React** คืออินเทอร์เฟซ **TypeScript** คือภาษา **Three.js** กับ **React Three Fiber** วาดลูกโลก **satellite.js** รัน SGP4 **Tailwind CSS** จัดสไตล์พาเนล

## รันบนเครื่อง

```bash
npm install
npm run dev
```

สำหรับ production

```bash
npm run build
npm run start
```
