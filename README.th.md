# Orbit

Orbit คือเว็บติดตามดาวเทียมไทยแบบ 3D ที่พัฒนาโดย Spaceth เพื่อให้ทุกคนเห็นได้ว่าดาวเทียมของไทยกำลังโคจรอยู่ตรงไหนเหนือโลก ผ่านภาพที่เข้าใจง่าย โต้ตอบได้ และไม่จำเป็นต้องใช้โปรแกรมติดตามดาวเทียมเฉพาะทาง

เว็บนี้ไม่ได้ “เดา” ตำแหน่งของดาวเทียมขึ้นมาเอง แต่ใช้ข้อมูลวงโคจรจริงที่เรียกว่า **OMM** แล้วนำมาคำนวณว่าดาวเทียมแต่ละดวงควรอยู่ที่ตำแหน่งใดในเวลาปัจจุบัน

## ทำไมถึงใช้ OMM แทน TLE

เดิม Orbit ใช้ข้อมูล **TLE** (Two-Line Element) แต่รูปแบบนี้กำลังถึงขีดจำกัด: หมายเลขแคตตาล็อก NORAD ใส่ได้เพียงห้าหลัก และ CelesTrak ได้ประกาศว่าหมายเลขห้าหลักนั้นหมดแล้ว

ตั้งแต่วันที่ **2026-07-11** เมื่อมีการเพิ่มดาวเทียม Saramago วัตถุที่ขึ้นทะเบียนใหม่จะได้หมายเลขแคตตาล็อก **หกหลัก** (100000+) และข้อมูล GP ของวัตถุเหล่านั้นจะ**ไม่มี**ในรูปแบบ TLE แบบเดิม ดูประกาศและแนวทางของ CelesTrak ได้ที่ [A New Way to Obtain GP Data](https://celestrak.org/NORAD/documentation/gp-data-formats.php)

ดังนั้น Orbit จึงย้ายมาใช้ **OMM** (Orbit Mean-Elements Message) ซึ่งเป็นรูปแบบ GP ที่มีโครงสร้างและรองรับอนาคตได้ดีกว่า ยังใช้แบบจำลอง **SGP4** ชุดเดิม เพื่อให้ติดตามดาวเทียมได้ต่อเมื่อแคตตาล็อกขยายเกินห้าหลัก

## OMM คืออะไร

**OMM** ย่อมาจาก **Orbit Mean-Elements Message** เป็นมาตรฐาน CCSDS สำหรับแลกเปลี่ยนองค์ประกอบวงโคจรแบบ mean elements ซึ่งเดิมเคยแจกจ่ายในรูปแบบ Two-Line Element (TLE) แต่ในรูปแบบที่มีโครงสร้าง อ่านด้วยเครื่องได้ง่าย (JSON / XML / KVN)

ภายใน OMM มีข้อมูลสำคัญของวงโคจร เช่น ความเอียงของวงโคจร mean motion ความรี และเวลา (epoch) ที่ข้อมูลชุดนั้นอ้างอิงถึง รวมถึงพารามิเตอร์แรงต้านที่ใช้กับ SGP4

อธิบายง่าย ๆ OMM คือ “ภาพ snapshot ล่าสุด” ของวงโคจรดาวเทียม จากข้อมูลชุดนี้ เราสามารถใช้แบบจำลองทางคณิตศาสตร์คำนวณต่อได้ว่า ดาวเทียมควรอยู่ตรงไหนในอีกไม่กี่นาทีข้างหน้า อีกหลายชั่วโมงข้างหน้า หรือย้อนกลับไปดูตำแหน่งในอดีตก็ได้

Orbit ไม่ได้เก็บตำแหน่งดาวเทียมไว้เป็นจุดสำเร็จรูป แต่จะดาวน์โหลด OMM ล่าสุด แล้วคำนวณตำแหน่งของดาวเทียมแบบ real-time ภายใน browser

## เว็บรู้ได้อย่างไรว่าดาวเทียมอยู่ตรงไหน

หลังจาก Orbit ได้ข้อมูล OMM แล้ว ระบบจะใช้แบบจำลองวงโคจรที่เรียกว่า **SGP4** เพื่อคำนวณตำแหน่งของดาวเทียม

SGP4 เป็นแบบจำลอง Simplified Perturbations มาตรฐานที่ใช้กับข้อมูล mean elements มาอย่างยาวนาน (เดิมใช้กับ TLE ปัจจุบันใช้กับ OMM ได้เช่นกัน) ให้คิดว่ามันคือเครื่องคิดเลขวงโคจรแบบดั้งเดิม ที่ยังถูกใช้กันอย่างแพร่หลายในการติดตามดาวเทียมจนถึงทุกวันนี้

โปรเจกต์นี้ใช้ **satellite.js** ซึ่งเป็น JavaScript library สำหรับอ่านข้อมูล OMM JSON และคำนวณตำแหน่งดาวเทียมด้วย SGP4

ขั้นตอนโดยรวมจะประมาณนี้

1. เว็บดาวน์โหลดข้อมูล OMM ของดาวเทียมแต่ละดวง
2. satellite.js อ่านข้อมูล OMM แล้วแปลงเป็นแบบจำลองวงโคจร
3. SGP4 คำนวณตำแหน่งของดาวเทียม ณ เวลาปัจจุบัน
4. ระบบแปลงตำแหน่งนั้นออกมาเป็น latitude, longitude, altitude และตำแหน่ง 3D บนโลก
5. เว็บแสดงตำแหน่งนั้นเป็นจุดดาวเทียมและเส้นวงโคจรบนโลก 3D

ดังนั้น OMM คือข้อมูลตั้งต้น, SGP4 คือวิธีคำนวณ และ satellite.js คือเครื่องมือที่ทำให้ทั้งหมดนี้ใช้งานบนเว็บได้จริง

## ข้อมูล OMM มาจากไหน

Orbit ดึงข้อมูล OMM (GP) จาก

**[CelesTrak](https://celestrak.org/)** (`gp.php` รูปแบบ JSON ตามหมายเลข NORAD)

อย่างไรก็ตาม เว็บไม่ได้เปิดให้ผู้ใช้ดึงข้อมูล OMM ของวัตถุอวกาศอะไรก็ได้ตามต้องการ Orbit ใช้ internal API เฉพาะกับดาวเทียมไทยที่อยู่ในรายการของโปรเจกต์เท่านั้น

ฝั่ง server จะมี route สำหรับดึงข้อมูล OMM ตาม NORAD ID เช่น THEOS-2, KnackSat-2, THEOS หรือ Thaicom ก่อนจะดึงข้อมูล ระบบจะตรวจสอบก่อนว่า NORAD ID นั้นอยู่ใน allowed list หรือไม่

เหตุผลคือเพื่อไม่ให้ API ของเว็บกลายเป็น open proxy ที่ใครก็ใช้ดึงข้อมูลอะไรก็ได้ และยังช่วยให้เราควบคุมรายการดาวเทียมได้ง่ายขึ้นด้วย

ข้อมูล OMM จะถูก cache ไว้ประมาณ 1 ชั่วโมง เพราะวงโคจรดาวเทียมไม่ได้เปลี่ยนทุกวินาทีเหมือนราคาหุ้น การ cache จึงช่วยให้เว็บโหลดเร็วขึ้น และลดการเรียก API ที่ไม่จำเป็น

## OMM สำรอง (Fallback)

หากดึงข้อมูลจาก CelesTrak ไม่ได้ Orbit จะใช้ข้อมูล OMM สำรองที่ฝังไว้ในโปรเจกต์ที่ `src/data/omm-fallback.json`

ระบบ fallback ทำงานสองชั้น

1. **ฝั่ง server** — route `/api/omm/[id]` จะลองดึงจาก CelesTrak ก่อน หากล้มเหลวจะส่งคืน OMM สำรองของดาวเทียมนั้นแทน
2. **ฝั่ง browser** — หากเรียก API route ไม่สำเร็จ client จะใช้ข้อมูลสำรองชุดเดียวกัน เพื่อให้ยังติดตามดาวเทียมได้แม้ API ล่มหรือออฟไลน์

โลก 3D และรายการดาวเทียมยังทำงานได้ด้วยข้อมูลสำรอง ข้อความ error พร้อมปุ่ม **ลองอีกครั้ง** จะแสดงเฉพาะเมื่อทั้ง API สดและข้อมูลสำรองใช้ไม่ได้

อัปเดตไฟล์สำรองจาก CelesTrak (แนะนำประมาณสัปดาห์ละครั้ง)

```bash
npm run update-omm-fallback
```

คำสั่งนี้จะดึง OMM ล่าสุดของดาวเทียมทุกดวงในรายการโปรเจกต์ แล้วเขียนทับ `src/data/omm-fallback.json`

## 3D View ใช้อะไรขับเคลื่อน

โลก 3D และการแสดงผลดาวเทียมของ Orbit สร้างขึ้นด้วย **Three.js** ผ่าน **React Three Fiber**

Three.js คือ library สำหรับสร้างกราฟิก 3D บนเว็บ ส่วน React Three Fiber ช่วยให้การใช้ Three.js ในโปรเจกต์ React ทำได้ง่ายและเป็นระบบมากขึ้น

ใน Orbit เครื่องมือเหล่านี้ถูกใช้ในการ render โลก 3D จุดดาวเทียม เส้นวงโคจร และการเคลื่อนกล้อง

โลกในฉากไม่ได้เป็นแค่ทรงกลมเรียบ ๆ แต่ใช้ข้อมูลแผ่นดินจาก Natural Earth วาดเป็น mesh แบบ vector ของแผ่นดินและมหาสมุทรโดยไม่มีเส้นพรมแดนประเทศ เส้นชายฝั่งยังเรียบเมื่อซูมเข้า และตัดเกาะเล็ก ๆ ออกเพื่อให้ globe โหลดได้เร็ว

จุดดาวเทียมถูกออกแบบให้มองเห็นได้เสมอ ไม่ว่าจะ zoom เข้าใกล้หรือถอยออกมาไกลแค่ไหน ขนาดของ marker จะถูกคำนวณใหม่ให้คงที่บนหน้าจอ แทนที่จะเล็กจนหายไปเมื่อ zoom out หรือใหญ่เกินไปเมื่อ zoom in

## มุมมองพื้นโลก

มุมมองพื้นโลกเป็นกล้องอีกตัว อยู่ข้างปุ่มเปลี่ยนภาษา มุมมองอวกาศมองลงมาที่โลก ส่วนมุมมองนี้ยืนอยู่บนพื้นแล้วมองขึ้นไปบนท้องฟ้า

กล้องอยู่เหนือพื้นเล็กน้อย ณ ละติจูดและลองจิจูดที่เลือก ในกรอบท้องถิ่นของทิศขึ้น ทิศเหนือ และทิศตะวันออก เริ่มต้นหันไปทางเหนือและเงยขึ้นจากขอบฟ้าเล็กน้อย การลากคือการคว้าท้องฟ้า ดาวจึงอยู่ใต้ตัวชี้ตลอด ล้อเมาส์เปลี่ยนความกว้างของภาพ จากพื้นโลก โลกเป็นทรงกลมสีเทาเข้มล้วน เพื่อให้ขอบฟ้าเรียบง่ายตอนมองท้องฟ้า mesh แผ่นดินยังอยู่เฉพาะในมุมมองอวกาศ

ดาวเทียมใช้ตำแหน่ง SGP4 ชุดเดียวกับมุมมองอวกาศ เมื่อเลือกดาวเทียม กล้องจะหันไปหาดวงนั้นและรักษาให้อยู่กลางภาพตามนาฬิกาจำลอง การลากท้องฟ้าจะปล่อยการติดตาม และการเลือกดาวเทียมอีกครั้งจะเริ่มติดตามใหม่ ตัวควบคุมเวลายังขยับท้องฟ้า ดวงจันทร์ ดาวเทียม และเส้นวงโคจรไปด้วยกัน

| กลุ่ม | สถานที่ |

### ท้องฟ้ามาจากไหน

ดาวฤกษ์ถึงโชติมาตร 6 มาจาก **XHIP** ซึ่งเป็นบัญชีต่อจาก Hipparcos (Anderson & Francis, 2012) ตามที่เผยแพร่ใน [d3-celestial](https://github.com/ofrohn/d3-celestial) ของ Olaf Frohn (`stars.6.json`) เส้นกลุ่มดาวเป็นรูปของสหพันธ์ดาราศาสตร์สากล พร้อมการปรับเส้นของ Frohn จากโปรเจกต์เดียวกัน (`constellations.lines.json`, สัญญา BSD-3-Clause) Orbit เก็บสำเนาย่อไว้ใน `src/data/skymap.json` เป็นไรต์แอสเซนชันและเดคลิเนชันยุค J2000

ในแต่ละเฟรม satellite.js ให้เวลาดาวฤกษ์กรีนิช แล้วหมุนบัญชีนั้นเข้ากรอบยึดโลกชุดเดียวกับดาวเทียม ดังนั้นท้องฟ้าจึงหมุนตามนาฬิกาจำลอง

ดวงจันทร์ใช้ตำแหน่ง geocentric ความละเอียดต่ำแบบ Meeus ใน `src/lib/moon.ts` ตำแหน่งนั้นอยู่ในกรอบยึดโลกอยู่แล้ว จึงปรากฏทั้งสองมุมมอง

## Orbit ทำอะไรได้บ้าง

Orbit สามารถแสดงดาวเทียมไทยหลายดวงพร้อมกันบนโลก 3D ผู้ใช้สามารถเลือกดาวเทียมแต่ละดวงเพื่อดูรายละเอียดเพิ่มเติมได้ เช่น ตำแหน่ง ความสูง ความเร็ว ข้อมูลภารกิจ วันปล่อย และหน่วยงานผู้ดำเนินงาน

ผู้ใช้ยังสามารถซ่อนหรือแสดงดาวเทียมแต่ละดวงได้ตามต้องการ เหมาะเวลาที่อยากโฟกัสเฉพาะดาวเทียมบางดวง หรือเวลาที่หน้าจอเริ่มดูเหมือนมีใครทำเส้นบะหมี่ตกใส่โลก

เมื่อเลือกดาวเทียม กล้องจะเคลื่อนไปโฟกัสที่ดาวเทียมดวงนั้นอย่างนุ่มนวล และเมื่อยกเลิกการเลือก กล้องจะกลับมายังมุมมองโลกปกติ

สามารถเปิดลิงก์ตรงไปยังดาวเทียมได้ด้วย path เช่น `/theos-2` Orbit จะโฟกัสดาวเทียมนั้น แล้วคงแถบที่อยู่ไว้ที่ `/` เพื่อไม่ให้การเปลี่ยนโฟกัสระหว่างใช้งาน remount ลูกโลก
Orbit ใช้โหมดมืดเท่านั้น โดย interface และฉาก 3D ใช้ theme เดียวกัน ทำให้ UI และ globe มีหน้าตาที่สอดคล้องกันทั้งเว็บ

## Tech Stack

Orbit พัฒนาด้วย **Next.js**, **React**, **TypeScript**, **Three.js**, **React Three Fiber**, **satellite.js** และ **Tailwind CSS**

สำหรับการคำนวณวงโคจร Orbit ใช้ satellite.js เพื่ออ่านข้อมูล OMM JSON และคำนวณตำแหน่งดาวเทียมด้วย SGP4

สำหรับมุมมอง 3D ใช้ Three.js และ React Three Fiber

สำหรับการดึงข้อมูล ใช้ Next.js API Route เพื่อ fetch และ cache ข้อมูล OMM จาก CelesTrak

สำหรับ styling ใช้ Tailwind CSS ร่วมกับ theme tokens ของโหมดมืด

## Deployment

Orbit เป็นโปรเจกต์ Next.js จึงสามารถรันบนเครื่องได้ด้วยคำสั่งมาตรฐาน

```bash
npm install
npm run dev
```

สำหรับ production

```bash
npm run build
npm run start
```

สรุปสั้น ๆ Orbit คือเว็บขนาดเล็กที่เชื่อมข้อมูลวงโคจรดิบ ๆ เข้ากับโลก 3D ที่มองเห็นและเล่นได้จริง มันเอา OMM mean elements มาแปลงเป็น globe แบบ interactive เพื่อให้ทุกคนเห็นได้ว่า ดาวเทียมไทยกำลังบินอยู่ตรงไหนเหนือโลก
